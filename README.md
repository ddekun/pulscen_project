# Pulscen Parser

Парсер каталога **Pulscen**, написанный на Python, для сбора информации о компаниях по выбранной категории товаров и городу с последующим сохранением данных в Excel.

## Цель проекта

Проект создан для автоматизации сбора контактных данных компаний с сайта Pulscen.  
С его помощью можно быстро получить структурированную таблицу организаций для анализа, поиска поставщиков и формирования базы контактов.

## Функциональность

- открытие страниц каталога Pulscen;
- обход нескольких страниц выдачи;
- поиск карточек компаний;
- извлечение названия компании;
- извлечение ссылки на компанию;
- извлечение адреса;
- раскрытие и получение номера телефона;
- сохранение результата в Excel.

## Логика работы

1. Скрипт открывает страницу каталога Pulscen по заданному URL.
2. Проходит по нескольким страницам результатов поиска.
3. На каждой странице находит карточки компаний.
4. Через Selenium нажимает на элементы показа телефона.
5. Получает данные из каждой карточки компании.
6. Сохраняет данные в список словарей.
7. Преобразует данные в `pandas.DataFrame`.
8. Экспортирует результат в Excel.

## Стек технологий

- **Python**
- **Selenium**
- **pandas**
- **requests**
- **BeautifulSoup**
- **lxml**
- **openpyxl**

## Структура проекта

- `pulscen_selenium.py` — основной рабочий скрипт;
- `pulscen_bs.py` — парсинг через BeautifulSoup;
- `pulscen_parser.py` — парсинг через lxml и XPath;
- `test.py` — тестовый запуск Selenium.

## Выходные данные

На выходе формируется Excel-файл с данными по компаниям:
- название,
- ссылка,
- адрес,
- телефон.
